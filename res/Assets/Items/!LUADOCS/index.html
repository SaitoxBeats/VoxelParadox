Item Lua API

Simple reference for the Lua runtime used by item script.lua files. This page documents the current API exposed by the game and shows practical item examples.

Overview Item Setup Entrypoint Context Fields Context Functions Behavior Notes Examples

Overview

A Lua item script is an optional script.lua file placed beside the item's item.json. The game loads that script when the player uses the item with the right mouse button.

The current runtime exposes a controlled gameplay API. Scripts can inspect player state, interact with inventory, open some HUD screens, play audio events, inspect the current target, print messages to the terminal, and send rich notifications to the in-game chat.

Scripts do not get access to save data, files, or arbitrary engine internals.

Item Setup

A script-driven item still needs to exist in the item registry and have a normal item.json. 

{
  "id": "lua_totem",
  "display_name": "Lua Totem",
  "categories": [ "utility", "quest" ],
  "stack_limit": 4,
  "icon_asset": "Assets/Textures/Items/portal_tracker.png",
  "on_use": {
    "cooldown": 0.5,
    "actions": [
      {
        "type": "print_terminal",
        "message": "[Items] Lua Totem is running its script."
      }
    ]
  },
  "script": {
    "enabled": true,
    "path": "script.lua"
  },
  "world_preview": {
    "use_texture_sprite": true
  }
}

In this model, the declarative on_use block runs first, then the Lua script runs after it.

Entrypoint

The script must define a global function named on_use(context).

function on_use(context)
    context.log("[Items][Lua] Script executed.")
    return true
end

Return values:

  • true: the item consumed the right-click use.
  • false: the script did not consume the use.
  • no return: treated like consumed by default.

Context Fields

Name Type Description
context.selected_item_id string Stable id of the currently selected item, such as lua_totem.
context.selected_count integer How many copies of the currently selected item are in the selected hotbar slot.
context.has_target boolean Whether the player currently has a valid block target under the crosshair.
context.target_block_id string Stable block id of the current target. Falls back to air when there is no target.
context.current_world_seed integer Seed of the currently active world.

Context Functions

Function Signature Description
log context.log(message) Prints a message to the game terminal.
push_notification context.push_notification(message_or_segments) Sends a chat notification. Pass a plain string for simple text or a segment table / array of segment tables for colored text.
get_player_life context.get_player_life() Returns current player health.
get_player_max_life context.get_player_max_life() Returns maximum player health.
is_player_alive context.is_player_alive() Returns whether the player is alive.
heal_player context.heal_player(amount) Adds health to the player, clamped by the game.
get_player_xp context.get_player_xp() Returns the player's current XP as a decimal number.
get_player_level context.get_player_level() Returns the player's current experience level as an integer.
set_player_xp context.set_player_xp(value) Sets the player's current XP using a decimal number.
add_player_xp context.add_player_xp(value) Adds decimal XP and uses the game's normal XP reward logic.
add_item context.add_item(item_id, amount) Attempts to add an item or block item to inventory. Returns true on success.
remove_item context.remove_item(item_id, amount) Attempts to remove an item or block item from inventory. Returns true on success.
count_item context.count_item(item_id) Returns how many copies of an item or block item the player currently has.
consume_selected context.consume_selected(amount) Consumes copies of the currently selected item from the selected slot. Returns true on success.
open_portal_tracker context.open_portal_tracker() Opens the same portal tracker menu used by the keyboard shortcut.
create_portal_for_target_block context.create_portal_for_target_block() Creates a portal on the block currently under the crosshair using the game's normal portal rules. Returns true when the portal exists or was created.
play_audio_event context.play_audio_event(event_id) Plays a registered audio event from Assets/Audio/Definitions/audio_events.json.
has_target context.has_target() Function version of the target-state check.
get_target_block_id context.get_target_block_id() Returns the stable id of the targeted block.
get_target_block_position context.get_target_block_position() Returns x, y, z integer coordinates of the targeted block.
get_target_normal context.get_target_normal() Returns the target face normal as x, y, z.
get_current_world_seed context.get_current_world_seed() Returns the current world seed.
get_selected_item_id context.get_selected_item_id() Returns the stable id of the selected inventory item.
get_selected_count context.get_selected_count() Returns the stack count in the selected hotbar slot.

Behavior Notes

  • Scripts run only on right-click item use.
  • Scripts do not run every frame. There is no tick hook in this version.
  • If the script has a syntax error or runtime error, the game logs the error and fails safely.
  • If your item also has declarative on_use, those actions run before Lua.
  • play_audio_event needs a valid audio event id such as ui.menu.click or player.item.pickup.
  • add_item, remove_item, and count_item accept the same textual ids used by chat commands and crafting.
  • create_portal_for_target_block respects the same portal creation cooldown and target rules used by the game.
  • push_notification accepts either a string, a single segment table, or an array of segment tables. Each segment table uses text and optional color = { r, g, b } with normalized RGB values.

Examples

1. Print a message and inspect world seed

function on_use(context)
    context.log("[Items][Lua] Current world seed: " .. tostring(context.get_current_world_seed()))
    return true
end

2. Heal the player only if they are hurt

function on_use(context)
    if context.get_player_life() < context.get_player_max_life() then
        context.heal_player(3)
        context.play_audio_event("player.item.pickup")
        return true
    end

    context.log("[Items][Lua] Player is already at full health.")
    return false
end

3. Open the portal tracker from an item

function on_use(context)
    context.open_portal_tracker()
    return true
end

4. Give an item reward

function on_use(context)
    local added = context.add_item("curio_shard", 2)

    if added then
        context.log("[Items][Lua] Granted 2 Curio Shards.")
        return true
    end

    context.log("[Items][Lua] Inventory is full.")
    return false
end

5. Require the player to look at a portal block

function on_use(context)
    if not context.has_target() then
        context.log("[Items][Lua] No block target.")
        return false
    end

    if context.get_target_block_id() ~= "portal" then
        context.log("[Items][Lua] You must look at a portal block.")
        return false
    end

    local x, y, z = context.get_target_block_position()
    context.log("[Items][Lua] Target portal at " .. x .. ", " .. y .. ", " .. z)
    context.play_audio_event("portal.enter")
    return true
end

6. Consume the selected item directly from Lua

function on_use(context)
    if context.get_selected_count() <= 0 then
        return false
    end

    local consumed = context.consume_selected(1)
    if consumed then
        context.log("[Items][Lua] Consumed one selected item.")
        return true
    end

    return false
end

7. Turn one item into another

function on_use(context)
    if context.count_item("curio_shard") < 3 then
        context.log("[Items][Lua] You need at least 3 Curio Shards.")
        return false
    end

    local removed = context.remove_item("curio_shard", 3)
    if not removed then
        return false
    end

    local added = context.add_item("healing_capsule", 1)
    if added then
        context.log("[Items][Lua] Crafted a Healing Capsule.")
        return true
    end

    context.log("[Items][Lua] Failed to add the new item.")
    return false
end

8. Example matching the current Lua Totem

function on_use(context)
    context.log("[Items][Lua] Lua Totem used in world seed " .. tostring(context.get_current_world_seed()))
    context.play_audio_event("ui.menu.click")

    if context.is_player_alive() and context.get_player_life() < context.get_player_max_life() then
        context.heal_player(1)
    end

    return true
end

9. Create a portal for the block under the crosshair

function on_use(context)
    if not context.has_target() then
        context.log("[Items][Lua] Look at a block first.")
        return false
    end

    if context.create_portal_for_target_block() then
        context.log("[Items][Lua] Portal created on the targeted block.")
        context.open_portal_tracker()
        return true
    end

    context.log("[Items][Lua] Could not create a portal right now.")
    return false
end

10. Add player XP from an item

function on_use(context)
    local before = context.get_player_xp()
    context.add_player_xp(2.5)
    local after = context.get_player_xp()

    context.log("[Items][Lua] XP changed from " .. tostring(before) .. " to " .. tostring(after))
    return true
end

11. Send a colored chat notification

function on_use(context)
    context.push_notification({
        { text = "You found your first " },
        { text = "versal", color = { 1.0, 0.82, 0.36 } },
        { text = "." }
    })

    return true
end
