Overview

A Lua item script is an optional script.lua file placed beside the item's item.json. The game loads and runs that script when the player right-clicks while holding the item.

The runtime exposes a controlled gameplay API. Scripts can:

  • Read and mutate player health, XP, and level.
  • Query and modify inventory (add, remove, count, consume).
  • Read player position, velocity, look direction, and movement state.
  • Inspect the current block target and adjacent placement position.
  • Create portals, open HUD screens, and play audio events.
  • Send plain or rich colored notifications to the in-game chat.

Scripts do not get access to save data, arbitrary files, or engine internals beyond what is listed here.

Item Setup

A script-driven item needs an item.json with "script" enabled. Declarative on_use actions (if present) run before the Lua script. 

{
  "id": "my_item",
  "display_name": "My Item",
  "categories": ["utility"],
  "stack_limit": 8,
  "icon_asset": "Assets/Textures/Items/versal.png",
  "on_use": {
    "cooldown": 0.4,
    "actions": [
      { "type": "play_sound", "event": "ui.menu.click" }
    ]
  },
  "script": {
    "enabled": true,
    "path": "script.lua"
  },
  "world_preview": {
    "use_texture_sprite": true
  }
}

Hooks

A script can define up to three global hook functions. Each is optional — the game probes for them when the session opens and only calls the ones that exist.

All three hooks share the same lua_State. Globals written in on_pickup or on_update are visible inside on_use and vice-versa.

on_pickup(context)

Called once when the player selects this item in the hotbar (or when the game starts with this item already selected). Use it to initialize per-session state, play a sound, or show a welcome hint. 

function on_pickup(context)
    context.log("[MyItem] picked up.")
    context.play_audio_event("player.item.pickup")
end

on_update(context, dt)

Called every frame while this item is selected. dt is the elapsed time in seconds since the last frame. Runs after on_pickup and before any on_use call in the same frame.

Keep this hook lightweight — it executes at the game's full simulation rate (typically 60 Hz). Avoid heavy allocations or expensive queries inside it. 

function on_update(context, dt)
    -- accumulate time in a global (persists across frames thanks to shared lua_State)
    _elapsed = (_elapsed or 0) + dt
end

on_use(context)

Called when the player right-clicks while holding the item. Return true to consume the use, false (or nothing) to decline it. 

function on_use(context)
    context.log("[MyItem] used after " .. string.format("%.1f", _elapsed or 0) .. "s in hand.")
    return true
end

Session Lifetime

The engine opens a fresh Lua session the moment the item is selected and closes it when the player switches away. Switching back opens a new session — globals do not survive hotbar slot changes. Use the player's inventory or XP APIs for persistent cross-session data.

Snapshot Fields

These are read-only values baked into the context table at the moment the item is used. They are plain Lua values, not function calls.

FieldTypeDescription
context.selected_item_id string Stable id of the selected item, e.g. "versal".
context.selected_count integer Stack count in the selected hotbar slot at use time.
context.selected_hotbar_index integer Zero-based index of the active hotbar slot at use time.
context.has_target boolean Whether the player had a valid block target under the crosshair at use time.
context.target_block_id string Stable block id of the target. Falls back to "air" when there is no target.
context.current_world_seed integer Seed of the currently active world at use time.
context.has_opened_first_portal boolean Persisted flag: true after the player's first successful portal creation. Stored in player.dat.
context.is_grounded boolean Whether the player was on the ground at use time.
context.is_crouching boolean Whether the player was crouching at use time.
context.movement_state string Movement state at use time. One of: "idle", "walking", "running", "crouching", "jumping", "falling".
context.is_sandbox_mode boolean Whether sandbox mode was active at use time.
context.player_xp_max number Maximum XP for the current level at use time.

Logging & Chat

FunctionSignatureReturnsDescription
log log(message: string) — Prints a message to the game terminal / stdout.
push_notification push_notification(message_or_segments) — Sends a chat notification. Pass a plain string for simple text, a single segment table, or an array of segment tables for colored text. Each segment table uses text and an optional color = {r, g, b} with normalized RGB values (0.0–1.0).

Player Health

FunctionSignatureReturnsDescription
get_player_life get_player_life() integer Current player health (life points).
get_player_max_life get_player_max_life() integer Maximum player health.
is_player_alive is_player_alive() boolean Returns true if the player is alive.
heal_player heal_player(amount: integer) — Adds amount life points, clamped to max by the engine.
damage_player damage_player(amount: integer) — Applies amount damage using the game's full damage pipeline (feedback effects, death check). Only positive values take effect.
set_player_health set_player_health(amount: integer) — Sets health to an exact value. Does not trigger damage feedback. Useful for curse or restore items. Prefer heal_player / damage_player for gameplay effects.

Player Experience

FunctionSignatureReturnsDescription
get_player_xp get_player_xp() number Current XP as a decimal. Resets toward 0 when a level is gained.
get_player_xp_max get_player_xp_max() number XP threshold required to reach the next level.
get_player_level get_player_level() integer Current experience level.
set_player_xp set_player_xp(value: number) — Directly sets the raw XP value. Bypasses the normal reward pipeline.
add_player_xp add_player_xp(value: number) — Adds XP using the game's normal reward logic (level-up events, item rewards).
set_player_level set_player_level(level: integer) — Sets the experience level directly, firing the appropriate engine events.

Player Physics & Movement

These functions return live values from the player's physics state at the moment of the call. The snapshot fields is_grounded, is_crouching, and movement_state provide the same data captured at use time.

get_player_velocity get_player_velocity() x, y, z: number Current velocity vector in world units per second.
get_player_look get_player_look() x, y, z: number Normalized forward direction the camera is pointing.
is_player_grounded is_player_grounded() boolean Returns true when the player is standing on a solid surface.
is_player_crouching is_player_crouching() boolean Returns true when the player is crouching.
get_movement_state get_movement_state() string One of: "idle", "walking", "running", "crouching", "jumping", "falling".

Player State Checks

FunctionSignatureReturnsDescription

player_has_spawnpoint player_has_spawnpoint() boolean Returns true when the player has a defined spawnpoint.
get_selected_hotbar_index get_selected_hotbar_index() integer Zero-based index of the currently selected hotbar slot.

Inventory

FunctionSignatureReturnsDescription
add_item add_item(item_id: string, amount?: integer) boolean Tries to add amount (default 1) of item_id to inventory. Returns true on success.
remove_item remove_item(item_id: string, amount?: integer) boolean Tries to remove amount (default 1) of item_id. Returns true on success.
has_item has_item(item_id: string) boolean Returns true if the player holds at least one of item_id.
count_item count_item(item_id: string) integer Returns the total count of item_id across all inventory slots.
consume_selected consume_selected(amount?: integer) boolean Consumes amount (default 1) copies from the currently selected hotbar slot. Returns true on success.

Item ids accept the same format used by crafting and chat commands. Block items use the block's own id (e.g. "stone", "crystal").

Portals & Audio

FunctionSignatureReturnsDescription
open_portal_tracker open_portal_tracker() — Opens the portal tracker menu. No-op if it is already open.
create_portal_for_target_block create_portal_for_target_block() boolean Creates a portal on the block under the crosshair using the normal portal rules (cooldown, valid target). Returns true when the portal exists or was just created.
play_audio_event play_audio_event(event_id: string) — Plays a registered audio event from Assets/Audio/Definitions/audio_events.json. Common ids: "ui.menu.click", "player.item.pickup", "portal.enter", "portal.exit".

Target & World

FunctionSignatureReturnsDescription
has_target has_target() boolean Live function version of the context.has_target snapshot field.

get_selected_count get_selected_count() integer Stack count in the selected slot. Function version of the snapshot field.

Behavior Notes

  • A script can define on_pickup, on_update, and/or on_use. All three are optional and share the same lua_State for the duration the item is held.
  • on_update runs every frame — keep it fast. Use a guard variable to rate-limit expensive logic (e.g. check once per second using an accumulated dt counter).
  • Switching hotbar slots destroys the current Lua session. Globals set in on_pickup / on_update do not persist across slot changes.
  • If the script has a syntax or runtime error, the game logs it and fails safely; the item use is not consumed.
  • If the item also has declarative on_use actions, those run before the Lua script.
  • Snapshot fields vs. functions: fields like context.is_grounded are baked once at use time. Functions like context.get_player_life() query current state. Both return the same data for calls made immediately inside on_use.
  • damage_player uses the full damage pipeline (screen flash, death sequence). For clean stat manipulation without effects, use set_player_health instead.
  • add_player_xp uses the game's reward logic and can trigger level-up events and item grants. For silent XP changes, use set_player_xp.
  • get_player_position returns camera (eye) position, not feet position. Subtract the eye height (~1.62) from Y for feet.
  • get_place_position is the block position adjacent to the target face — useful for logic that depends on where a block would be placed without actually placing it.
  • add_item, remove_item, has_item, and count_item accept the same textual ids used by chat commands and crafting recipes.
  • create_portal_for_target_block respects the portal cooldown and target requirements enforced by the engine.
  • push_notification accepts: a plain string, a single segment table { text="…", color={r,g,b} }, or an array of such tables. RGB values are normalized (0.0–1.0).

Examples

1. Log world seed

function on_use(context)
    context.log("[MyItem] World seed: " .. tostring(context.current_world_seed))
    return true
end

2. Healing potion (only heals when hurt)

function on_use(context)
    if not context.is_player_alive() then
        return false
    end

    if context.get_player_life() >= context.get_player_max_life() then
        context.push_notification("Already at full health.")
        return false
    end

    context.heal_player(4)
    context.play_audio_event("player.item.pickup")
    context.consume_selected(1)
    return true
end

3. Curse shard (damages the player who uses it)

function on_use(context)
    if not context.is_player_alive() then
        return false
    end

    context.damage_player(2)
    context.add_player_xp(5.0)
    context.push_notification({
        { text = "The shard bites back. " },
        { text = "+5 XP", color = { 0.4, 1.0, 0.4 } }
    })
    context.consume_selected(1)
    return true
end

4. XP tome (grants a full level)

function on_use(context)
    local level = context.get_player_level()
    context.set_player_level(level + 1)
    context.play_audio_event("player.item.pickup")
    context.push_notification({
        { text = "Level up! Now level " },
        { text = tostring(level + 1), color = { 1.0, 0.82, 0.3 } }
    })
    context.consume_selected(1)
    return true
end

5. Require crouching to activate

function on_use(context)
    if not context.is_crouching then   -- snapshot field
        context.push_notification("Crouch to use this item.")
        return false
    end

    context.play_audio_event("portal.enter")
    context.log("[MyItem] Activated while crouching.")
    return true
end

6. Item that behaves differently while airborne

function on_use(context)
    local state = context.movement_state  -- snapshot field

    if state == "jumping" or state == "falling" then
        context.push_notification({
            { text = "Air boost!", color = { 0.5, 0.8, 1.0 } }
        })
        context.add_player_xp(1.0)
        return true
    end

    context.push_notification("Jump first to trigger the air boost.")
    return false
end

7. Read player position for debug

function on_use(context)
    local x, y, z = context.get_player_position()
    local vx, vy, vz = context.get_player_velocity()
    local fx, fy, fz = context.get_player_look()

    context.log(string.format(
        "[Pos] %.1f  %.1f  %.1f  |  [Vel] %.2f  %.2f  %.2f  |  [Look] %.2f  %.2f  %.2f",
        x, y, z, vx, vy, vz, fx, fy, fz
    ))
    return true
end

8. Open the portal tracker

function on_use(context)
    context.open_portal_tracker()
    return true
end

9. Create a portal on the targeted block

function on_use(context)
    if not context.has_target() then
        context.push_notification("Look at a block first.")
        return false
    end

    if context.create_portal_for_target_block() then
        local x, y, z = context.get_target_block_position()
        context.log("[Portal] Created at " .. x .. ", " .. y .. ", " .. z)
        context.open_portal_tracker()
        return true
    end

    context.push_notification("Could not create a portal right now.")
    return false
end

10. First-portal welcome message

function on_use(context)
    local is_first = not context.has_opened_first_portal

    if not context.has_target() then
        return false
    end

    if context.create_portal_for_target_block() then
        if is_first then
            context.push_notification({
                { text = "Your first portal has opened!  " },
                { text = "Press F to dive in.", color = { 0.31, 1.0, 0.28 } }
            })
        end
        context.remove_item("versal", 1)
        return true
    end

    return false
end

11. Get placement position (adjacent face)

function on_use(context)
    if not context.has_target() then
        context.push_notification("No target.")
        return false
    end

    local px, py, pz = context.get_place_position()
    local nx, ny, nz = context.get_target_normal()

    context.log(string.format(
        "[Place] Position %d,%d,%d  Normal %d,%d,%d",
        px, py, pz, nx, ny, nz
    ))
    return true
end

12. Item exchange (3 shards → 1 capsule)

function on_use(context)
    if context.count_item("curio_shard") < 3 then
        context.push_notification("Need at least 3 Curio Shards.")
        return false
    end

    if not context.remove_item("curio_shard", 3) then
        return false
    end

    if context.add_item("healing_capsule", 1) then
        context.push_notification({
            { text = "Crafted a " },
            { text = "Healing Capsule", color = { 0.4, 1.0, 0.6 } },
            { text = "." }
        })
        return true
    end

    -- Inventory full — give shards back
    context.add_item("curio_shard", 3)
    context.push_notification("Inventory is full.")
    return false
end

13. Check breaking progress for a charged ability

function on_use(context)
    if context.is_breaking_block() then
        local pct = math.floor(context.get_breaking_progress() * 100)
        context.log("[Drill] Breaking at " .. pct .. "% progress.")
    end
    return true
end

function on_use(context)

    end

    context.set_player_health(context.get_player_max_life())

17. Passive regeneration — heal 1 HP every 3 seconds while held

local _regen_timer = 0

function on_pickup(context)
    _regen_timer = 0
    context.push_notification("Regen ring equipped.")
end

function on_update(context, dt)
    if not context.is_player_alive() then return end

    _regen_timer = _regen_timer + dt
    if _regen_timer >= 3.0 then
        _regen_timer = 0

        local hp    = context.get_player_life()
        local maxHp = context.get_player_max_life()
        if hp < maxHp then
            context.heal_player(1)
        end
    end
end

function on_use(context)
    local hp = context.get_player_life()
    context.push_notification("HP: " .. tostring(hp))
    return true
end

18. XP meter — log progress toward next level each second

local _tick = 0

function on_update(context, dt)
    _tick = _tick + dt
    if _tick < 1.0 then return end
    _tick = 0

    local xp    = context.get_player_xp()
    local xpMax = context.get_player_xp_max()
    local pct   = (xpMax > 0) and math.floor(xp / xpMax * 100) or 0
    context.log("[XP] " .. tostring(pct) .. "% to next level")
end
